# RealDash Mirror v1.0.7 Free - Pitlane fixes

## What changed

- Fixed the guided game selector: advanced filters no longer hide EVO from
  Pitlane. Known games are listed first, with readable window names.
- Network viewing is enabled by default, with visible Dash, Output 2 and
  Output 3 links and copy actions in the output setup.
- HDMI is optional and disabled by default for new setups. The primary
  display is reserved for the game and cannot be selected as an HDMI output.
- Saved HDMI selections are restored only when the secondary display is
  available. Disconnected displays do not fall back to the primary screen.
- Final confirmation checks that each enabled crop has a usable destination:
  network viewing or a selected secondary HDMI display.

## Quick start

1. Extract the Free SingleFile ZIP and launch `DashMirrorOverscan.exe`.
2. In Pitlane, select your running game to start the preview.
3. Adjust the area below the screen, then choose **Apply and continue**.
4. Position your crops. Leave Network enabled for phones, tablets or TV browsers;
   enable HDMI only when using selected secondary displays.
5. Validate crops, then launch the session. Automatic Mini Pin remains available.
6. Open `http://<pc-lan-ip>:5055/` on the same LAN, or copy the output-specific
   link. The existing Android Viewer APK remains compatible and is unchanged.

Free capture sessions are limited to 10 minutes. A valid Pro license unlocks
unlimited capture. Windows SingleFile and PortableFallback ZIPs are included,
along with a manifest containing version, edition and SHA-256 checksums.

## Validation and limits

- 101 automated tests passed; Release build completed without warnings or errors.
- Live Pro validation on EVO: 5120 x 1440 screen, bottom 540 overscan producing
  a 5120 x 1980 capture, 960 x 540 dashboard crop preserved at session launch,
  HTTP dashboard snapshot received, `/health` OK and automatic Mini Pin visible.
- Physical secondary HDMI displays and Android device playback were not tested
  for this patch. No 30 FPS guarantee: observed live telemetry was about
  22 FPS capture and 20 FPS encoding on the test setup.
- Keep the game restored while driving. A minimized game may stop producing
  frames; the viewer can retain its last image when capture stops.
- Some games do not render hidden overscan. No injection, EDID changes or
  automatic Windows display-mode changes are performed.

The application source repository remains private; this public release contains
Free binaries and user-facing documentation only.
