# RealDash Mirror v1.0.6 Free - Pitlane

A simpler cockpit setup: choose your game, extend the area below the screen,
frame your outputs, then confirm and launch the session.

- New Pitlane layout with saved car profiles and four steps on the left, a large
  central preview, and a fixed confirmation bar.
- The Studio-inspired **Area below the screen** slider stays beside the preview
  during overscan and crop setup. It uses the same setting as saved profiles
  and advanced controls.
- Dash, Output 2 and Output 3 are grouped below the preview. Extra outputs can
  be disabled. Network viewing and HDMI output controls remain available.
- Selecting a game starts preview without immediately changing its resolution.
- Final confirmation checks every enabled crop against the actual capture.
  Launching a confirmed Pitlane session preserves crop and resolution settings.
- Optional automatic Mini Pin after a successful launch.
- Quieter header, fixed-height notifications, readable profile names, EN/FR
  labels, and settings for license, updates, network URL and QR code.
- Fixed localization replacing live text bindings and a shutdown exception
  when a second app instance was rejected.

## Downloads

- **Free SingleFile ZIP**: recommended Windows portable EXE.
- **Free PortableFallback ZIP**: self-contained folder if single-file startup fails.
- **Manifest JSON**: version, edition, source revision and SHA-256 checksums.
- The existing Android Viewer remains compatible; this release changes Windows UI.

## Quick start

1. Extract the Windows ZIP and run `DashMirrorOverscan.exe`.
2. In **Pitlane**, choose the running game, or apply a saved car profile.
3. Adjust **Area below the screen**, then **Apply and continue**.
4. Position Dash and any enabled Output 2/3 crops. Select Network viewer and/or
   HDMI outputs, and the HDMI displays.
5. **Confirm crops**, then **Launch my session**. Mini Pin is enabled by default.
6. Open `http://<pc-lan-ip>:5055/` on the same LAN, or scan the QR in Settings.
   Use `/tv`, `/output2` or `/output3` for additional browser views.

Free capture is limited to 10 minutes per session. A valid Pro license unlocks
unlimited capture. The source repository remains private.

Some games do not render the hidden overscan region, even if Windows accepts
the window size. Game-specific compatibility and GPU load still apply. Use
**Restore game** to return to the original window placement. No monitor mode,
EDID or Windows display topology is changed automatically.
